# composition

Tools for displaying multiple animations at once.

Classes

| Name | Description |
| --- | --- |
| [`AnimationGroup`](https://docs.manim.community/en/stable/reference/manim.animation.composition.AnimationGroup.html) | Plays a group or series of [`Animation`](https://docs.manim.community/en/stable/reference/manim.animation.animation.Animation.html). |
| [`LaggedStart`](https://docs.manim.community/en/stable/reference/manim.animation.composition.LaggedStart.html) | Adjusts the timing of a series of [`Animation`](https://docs.manim.community/en/stable/reference/manim.animation.animation.Animation.html) according to `lag_ratio`. |
| [`LaggedStartMap`](https://docs.manim.community/en/stable/reference/manim.animation.composition.LaggedStartMap.html) | Plays a series of [`Animation`](https://docs.manim.community/en/stable/reference/manim.animation.animation.Animation.html) while mapping a function to submobjects. |
| [`Succession`](https://docs.manim.community/en/stable/reference/manim.animation.composition.Succession.html) | Plays a series of animations in succession. |
