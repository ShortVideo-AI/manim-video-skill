# transform\_matching\_parts

Animations that try to transform Mobjects while keeping track of identical parts.

Classes

| Name | Description |
| --- | --- |
| [`TransformMatchingAbstractBase`](https://docs.manim.community/en/stable/reference/manim.animation.transform_matching_parts.TransformMatchingAbstractBase.html) | Abstract base class for transformations that keep track of matching parts. |
| [`TransformMatchingShapes`](https://docs.manim.community/en/stable/reference/manim.animation.transform_matching_parts.TransformMatchingShapes.html) | An animation trying to transform groups by matching the shape of their submobjects. |
| [`TransformMatchingTex`](https://docs.manim.community/en/stable/reference/manim.animation.transform_matching_parts.TransformMatchingTex.html) | A transformation trying to transform rendered LaTeX strings. |
