# tex\_mobject

Mobjects representing text rendered using LaTeX.

Important

See the corresponding tutorial [Text With LaTeX](https://docs.manim.community/en/stable/guides/using_text.html)

Note

Just as you can use [`Text`](https://docs.manim.community/en/stable/reference/manim.mobject.text.text_mobject.Text.html) (from the module [`text_mobject`](https://docs.manim.community/en/stable/reference/manim.mobject.text.text_mobject.html)) to add text to your videos, you can use [`Tex`](https://docs.manim.community/en/stable/reference/manim.mobject.text.tex_mobject.Tex.html) and [`MathTex`](https://docs.manim.community/en/stable/reference/manim.mobject.text.tex_mobject.MathTex.html) to insert LaTeX.

Classes

| Name | Description |
| --- | --- |
| [`BulletedList`](https://docs.manim.community/en/stable/reference/manim.mobject.text.tex_mobject.BulletedList.html) | A bulleted list. |
| [`MathTex`](https://docs.manim.community/en/stable/reference/manim.mobject.text.tex_mobject.MathTex.html) | A string compiled with LaTeX in math mode. |
| [`MathTexPart`](https://docs.manim.community/en/stable/reference/manim.mobject.text.tex_mobject.MathTexPart.html) |  |
| [`SingleStringMathTex`](https://docs.manim.community/en/stable/reference/manim.mobject.text.tex_mobject.SingleStringMathTex.html) | Elementary building block for rendering text with LaTeX. |
| [`Tex`](https://docs.manim.community/en/stable/reference/manim.mobject.text.tex_mobject.Tex.html) | A string compiled with LaTeX in normal mode. |
| [`Title`](https://docs.manim.community/en/stable/reference/manim.mobject.text.tex_mobject.Title.html) | A mobject representing an underlined title. |
