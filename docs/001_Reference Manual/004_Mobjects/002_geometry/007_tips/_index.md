# tips

A collection of tip mobjects for use with [`TipableVMobject`](https://docs.manim.community/en/stable/reference/manim.mobject.geometry.arc.TipableVMobject.html).

Classes

| Name | Description |
| --- | --- |
| [`ArrowCircleFilledTip`](https://docs.manim.community/en/stable/reference/manim.mobject.geometry.tips.ArrowCircleFilledTip.html) | Circular arrow tip with filled tip. |
| [`ArrowCircleTip`](https://docs.manim.community/en/stable/reference/manim.mobject.geometry.tips.ArrowCircleTip.html) | Circular arrow tip. |
| [`ArrowSquareFilledTip`](https://docs.manim.community/en/stable/reference/manim.mobject.geometry.tips.ArrowSquareFilledTip.html) | Square arrow tip with filled tip. |
| [`ArrowSquareTip`](https://docs.manim.community/en/stable/reference/manim.mobject.geometry.tips.ArrowSquareTip.html) | Square arrow tip. |
| [`ArrowTip`](https://docs.manim.community/en/stable/reference/manim.mobject.geometry.tips.ArrowTip.html) | Base class for arrow tips. |
| [`ArrowTriangleFilledTip`](https://docs.manim.community/en/stable/reference/manim.mobject.geometry.tips.ArrowTriangleFilledTip.html) | Triangular arrow tip with filled tip. |
| [`ArrowTriangleTip`](https://docs.manim.community/en/stable/reference/manim.mobject.geometry.tips.ArrowTriangleTip.html) | Triangular arrow tip. |
| [`StealthTip`](https://docs.manim.community/en/stable/reference/manim.mobject.geometry.tips.StealthTip.html) | 'Stealth' fighter / kite arrow shape. |
