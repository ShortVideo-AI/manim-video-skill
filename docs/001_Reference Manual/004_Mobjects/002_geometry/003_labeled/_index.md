# labeled

Mobjects that inherit from lines and contain a label along the length.

Classes

| Name | Description |
| --- | --- |
| [`Label`](https://docs.manim.community/en/stable/reference/manim.mobject.geometry.labeled.Label.html) | A Label consisting of text surrounded by a frame. |
| [`LabeledArrow`](https://docs.manim.community/en/stable/reference/manim.mobject.geometry.labeled.LabeledArrow.html) | Constructs an arrow containing a label box somewhere along its length. |
| [`LabeledLine`](https://docs.manim.community/en/stable/reference/manim.mobject.geometry.labeled.LabeledLine.html) | Constructs a line containing a label box somewhere along its length. |
| [`LabeledPolygram`](https://docs.manim.community/en/stable/reference/manim.mobject.geometry.labeled.LabeledPolygram.html) | Constructs a polygram containing a label box at its pole of inaccessibility. |
