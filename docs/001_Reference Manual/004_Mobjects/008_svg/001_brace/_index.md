# brace

Mobject representing curly braces.

Classes

| Name | Description |
| --- | --- |
| [`ArcBrace`](https://docs.manim.community/en/stable/reference/manim.mobject.svg.brace.ArcBrace.html) | Creates a [`Brace`](https://docs.manim.community/en/stable/reference/manim.mobject.svg.brace.Brace.html) that wraps around an [`Arc`](https://docs.manim.community/en/stable/reference/manim.mobject.geometry.arc.Arc.html). |
| [`Brace`](https://docs.manim.community/en/stable/reference/manim.mobject.svg.brace.Brace.html) | Takes a mobject and draws a brace adjacent to it. |
| [`BraceBetweenPoints`](https://docs.manim.community/en/stable/reference/manim.mobject.svg.brace.BraceBetweenPoints.html) | Similar to Brace, but instead of taking a mobject it uses 2 points to place the brace. |
| [`BraceLabel`](https://docs.manim.community/en/stable/reference/manim.mobject.svg.brace.BraceLabel.html) | Create a brace with a label attached. |
| [`BraceText`](https://docs.manim.community/en/stable/reference/manim.mobject.svg.brace.BraceText.html) | Create a brace with a text label attached. |
