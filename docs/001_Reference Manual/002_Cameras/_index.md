# Cameras

| Name | Description |
| --- | --- |
| [`camera`](https://docs.manim.community/en/stable/reference/manim.camera.camera.html) | A camera converts the mobjects contained in a Scene into an array of pixels. |
| [`mapping_camera`](https://docs.manim.community/en/stable/reference/manim.camera.mapping_camera.html) | A camera module that supports spatial mapping between objects for distortion effects. |
| [`moving_camera`](https://docs.manim.community/en/stable/reference/manim.camera.moving_camera.html) | Defines the MovingCamera class, a camera that can pan and zoom through a scene. |
| [`multi_camera`](https://docs.manim.community/en/stable/reference/manim.camera.multi_camera.html) | A camera supporting multiple perspectives. |
| [`three_d_camera`](https://docs.manim.community/en/stable/reference/manim.camera.three_d_camera.html) | A camera that can be positioned and oriented in three-dimensional space. |
